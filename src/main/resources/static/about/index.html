Based in Tempe, Arizona, I build Java applications, backend services, and practical user interfaces.

This project brings together a Java desktop game, a Spring Boot leaderboard service, and a responsive web interface.

Inspiration

Snake worked because it was instantly understandable — and brutally addictive once you started chasing your own best score.

📟

Nokia-era simplicity

Simple controls, fast resets, and a tight feedback loop. No tutorials needed.

🔁

“One more run” loop

Each run is short, which makes improvement feel achievable — and keeps you playing.

🏁

Competition

The original didn’t need online play — but leaderboards make it instantly competitive.

What’s new in this version

Same nostalgic feel, but with modern engineering behind it.

Desktop + leaderboard-backed runs

The main experience is a desktop client. Finishing a run can submit to an online leaderboard.

Java Swing client Session-protected submits

A real backend service

Leaderboards are served by a deployed Spring Boot API with clean contracts, pagination, and validation.

Spring Boot REST DTOs Pagination

Project features

Highlights across the desktop game, online competition, and supporting backend service.

Desktop game

Java 21 and Swing power Standard, Map Select, Race, and AI modes.

Maps and AI

Ten packaged maps pair with Chase, Safe, and Survival A* strategies.

Online rankings

Spring Boot and PostgreSQL rank eligible runs by mode, map, and difficulty.

Tested delivery

Maven tests and GitHub Actions validate changes before Koyeb deployment.

Play it

Download the desktop version for the full experience, or browse the leaderboard on the web.
