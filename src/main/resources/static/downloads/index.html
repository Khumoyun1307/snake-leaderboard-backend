How to run

Quick start instructions for the desktop client. Update these once your packaging is finalized.

Run the JAR

Requires Java installed (JRE/JDK).

java -jar snake-client.jar
  • Open the game
  • Play a run
  • View your score on the online leaderboard

Troubleshooting

  • No Java? Install a recent JDK (17+ recommended).
  • Offline? Leaderboard pages still load, but submissions may fail.
  • Firewall? Allow outbound HTTPS for API calls.
