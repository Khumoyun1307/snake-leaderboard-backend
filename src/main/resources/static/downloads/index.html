How to run

Quick start instructions for the runnable JAR published with each release.

Run the JAR

Requires a Java 21 JRE or JDK.

java -jar SnakeGame.jar
  • Open the game
  • Play a run
  • Submit a finished non-AI run to the optional online leaderboard

Troubleshooting

  • No Java? Install a Java 21 JRE or JDK to run the JAR.
  • Offline? The game remains playable, but online leaderboard requests cannot complete.
  • Firewall? Allow outbound HTTPS for API calls.
