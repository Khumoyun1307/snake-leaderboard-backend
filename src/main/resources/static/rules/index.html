How to play

A step by step view for players who have never played Snake before.

Start a run

  • Launch the desktop client.
  • Choose Standard, Map Select, Race, or AI from the menu.
  • Set the speed and optional obstacles in Difficulty settings.
  • Select an unlocked map when using Map Select.
  • Each run begins with a normal apple at an unoccupied grid cell.

Move and turn

  • Use the arrow keys to change direction.
  • You can only turn 90 degrees.
  • An immediate 180-degree reversal is ignored.
  • Crossing any edge wraps the snake to the opposite side.
  • Press Space to pause the run.

Core rules

These rules apply across all maps and modes unless noted.

Movement rules

  • The snake moves one grid unit per tick.
  • Turning is instant at the next grid step.
  • The selected difficulty determines the base tick speed.
  • A Slowdown apple temporarily increases the tick delay.
  • Space pauses movement and opens the pause menu.

Collision rules

  • The board has no lethal border; every edge wraps.
  • Running into your own body ends the run.
  • Touching a static obstacle ends the run.
  • Touching an enabled moving obstacle ends the run.

Food, growth, and items

Every apple grows the snake by one segment. Apple type determines its point value and any temporary effect.

FO

Normal

The standard red apple awards 1 point.

Every apple adds one body segment.

SP

Big and Golden

Big awards 4 points; Golden awards 2 and activates double scoring for about 10 seconds.

They are scheduled after 8 and 17 eaten apples.

IT

Slowdown and Reverse

Both award 1 point. Slowdown reduces the pace; Reverse temporarily inverts the arrow keys.

Slowdown follows 25 eaten apples; Reverse follows a positive score divisible by 50. Their effects last about 8 seconds.

Maps

The game includes ten numbered maps with fixed obstacle layouts, plus an open basic board.

01

Basic board

Standard mode uses the open board and can add random static or moving obstacles.

Its edges wrap just like every packaged map.

02

Maps 1-10

Each packaged map defines a different fixed arrangement of blocked grid cells.

Map 1 starts unlocked; Race progress unlocks later maps.

03

Map progression

Map Select plays one unlocked map; Race begins on Map 1 and advances in order.

Race advances after the configured number of apples.

Map rules
Map files define only fixed obstacle cells. Toroidal edge wrapping remains active on every map.

Modes

Player runs use Standard, Map Select, or Race; AI mode drives the snake with an A* strategy.

STD

STANDARD

Endless play on the basic board with optional random and moving obstacles.

AI mode can instead use Chase, Safe, or Survival behavior.

MAP

MAP SELECT

Choose a specific map before starting a run.

Only unlocked packaged maps are available in normal play.

RCE

RACE

Start on Map 1 and advance through sequential maps by eating the configured apple threshold.

The default threshold is 20 apples per map.

Difficulty and speed

The 0-50 difficulty slider changes movement speed; it does not change apple values.

Available difficulties

  • Levels 0-19: Beginner or Easy, recorded as EASY.
  • Levels 20-29: Medium, recorded as NORMAL.
  • Levels 30-39: Hard, recorded as HARD.
  • Levels 40-49: Expert, recorded as EXPERT.
  • Level 50: Insane, recorded as INSANE.

What changes

  • Base tick delay ranges from 180 ms at level 0 to 60 ms at level 50.
  • Slowdown temporarily adds 60 ms to the active tick delay.
  • Static and moving obstacles are separate settings.
  • The run's difficulty label is included with leaderboard submissions.

Scoring and progress

The score is the sum of apple values, with active Golden double scoring applied when an apple is collected.

Score basics

  • Normal, Slowdown, and Reverse apples award 1 point.
  • Big apples award 4 points.
  • Golden apples award 2 points and start a temporary double-score effect.
  • Difficulty and survival time do not add points.
Normal +1 | Big +4 | Golden +2 | Slowdown +1 | Reverse +1

Progress stages

  • Each apple grows the snake by one segment.
  • Race preserves the score while advancing to the next map.
  • The last run and highest-scoring run are saved as deterministic replays.
  • A run ends after a self, static-obstacle, or moving-obstacle collision.

Game features

Systems that support gameplay and leaderboards.

LB

Online leaderboard

Runs can submit scores to the backend API.

Scores filter by map, mode, difficulty.

SS

Save and replay

Pause a run to save it, then continue later from the main menu.

Watch-only last-run and best-run replays are recorded automatically.

OF

Offline play

You can still play without a connection.

Leaderboard submits may fail while offline.

Tips for new players

Simple advice to last longer and score higher.

Movement tips

  • Keep to the edges early to avoid self traps.
  • Leave escape lanes when turning into tight spaces.
  • Plan two moves ahead at higher speeds.

Scoring tips

  • Focus on survival over risky shortcuts.
  • Use the basic board and a lower difficulty to learn the controls.
  • Practice a single map to master routes.
